## Sobre

Engenheiro de Dados. Meu trabalho é tirar dado do lugar onde ele nasce, tratar e entregar onde ele vira decisão — pipelines na AWS, APIs em Python e agentes de IA que fazem o caminho sozinhos.

Aqui fica o que eu construo por conta própria: side-projects, experimentos com IA aplicada e o TCC. Código de trabalho mora em outra conta.

|  |  |
|---|---|
| **Hoje** | Pipelines de dados, APIs e agentes de IA na AWS |
| **Formação** | Sistemas de Informação — FURB |
| **Base** | Blumenau, Santa Catarina, Brasil |
| **Ambiente** | Arch Linux |
